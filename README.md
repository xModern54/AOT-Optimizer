# AOT Optimizer
Android app for rooted Android devices for manually managing AOT compilation and optimization of installed apps.

## Features
- Force ART compilation modes per app
- Save per-app target mode and restore it after app updates (drift detection)
- Batch optimize multiple apps
- Show compiled artifact size / storage impact
- Option to disable system background dexopt to avoid interference

## Requirements
- Root access
- Android device

## Disclaimer
This tool changes runtime compilation state. Use carefully.
